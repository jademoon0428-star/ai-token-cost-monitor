AI Cost Management
Version 1.3.0

Purpose:
A local Windows-first AI cost monitoring and management application.

v1.3.0 highlights:
- Corrected Dashboard verified-record semantics.
- Added Saving cost concentration evidence.
- Added Efficiency evidence to Saving.
- Added verified Money Layer efficiency metrics.
- Improved Usage wording to distinguish all-time stored records from the selected reporting period.
- Preserved the separation between verified monetary data and local Activity evidence.
- No monetary savings are fabricated without reliable comparison data.

Data policy:
Only source-reported verified or exact costs are counted as monetary cost.
Local Activity evidence is not converted into estimated monetary cost.

Installation:
Run AI-Cost-Management-Setup.exe.

User data:
User data is stored under:
%APPDATA%\AI-Cost-Management\data

Upgrade behavior:
Existing user data is preserved during installation.
