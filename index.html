Know what your AI actually costs — with evidence.

AI Cost Management is a local-first Windows desktop app for high-frequency AI users and multi-model workflows. It records verifiable, source-reported costs in a local database on your machine, and shows what AI activity is happening locally — as evidence, not guesses.

Bills are scattered

Your AI spending is spread across providers, models, and tools, each dashboard showing only its own slice. Reconciling those numbers by hand does not scale when the model mix changes weekly.

What is in version 1.5.5

Monitoring and visibility — nothing more, nothing less.

Dashboard

Today's and recent verified spending, broken down by provider, model, and day, with attention signals for unusual changes.

Usage records

Inspect model, provider, token, and cost records with a full details view. Unknown costs stay unknown — they are never estimated.

Saving insights

See where your verified spending is concentrated and what is driving it, so you can decide where to cut — with real numbers, not rules of thumb.

Budget status

Daily, weekly, and monthly budgets computed from verified cost data, with in-page status, progress, and forecasts. Display only — it does not block spending and sends no notifications.

AI Activity (on-demand snapshot)

Scan local AI-related processes and network connections on Windows, using local evidence. Evidence only — not proof of spending. Results are kept in memory and cleared when the app restarts. Detection may produce false positives. There is no background monitoring.

DeepSeek official export import

Import the official DeepSeek usage export ZIP directly into the local database. No API keys required, parsed locally, prices preserved in the original currency (CNY).

Built-in price registry

Ships with version 1.5.5: verified price information for 4 providers and 10 models, read from vendor documentation and seeded into the local database automatically on first launch — ready before you import anything. Bundled with this release — we do not promise automatic or real-time price updates.

Scope of v1.5.5: this release monitors and explains costs. It does not automatically switch models, run automatic cost optimization, recommend model combinations, analyze productivity, or track monthly subscriptions.

Local-first by design

Your records stay in a local database

All records live in a local SQLite database on your computer (on the installed app: %APPDATA%\AI-Cost-Management\data\). Uninstalling the app preserves your data.

No account, no cloud sync

There is no login and no server side. We found no code paths that upload your usage or cost data, and no analytics or crash-reporting code in the application.

Honest about network traffic

We do not claim the app makes zero network requests. Being precise:

  • Opening the AI Activity page may send reverse DNS lookups for remote IPs your machine is connected to.
  • The optional provider connectivity test contacts that provider's API — only when you trigger it.
  • Your usage and cost data is not uploaded — we found no code path that uploads it.

FAQ

Do I need API keys to use it?

No. The core features — Dashboard, usage records, budget status, saving views, and AI Activity snapshots — run without any API key, and importing a DeepSeek official export ZIP requires none either. These are separate from the optional provider connectivity test, which contacts the provider's API only when you run it.

Where is my data stored?

In a local SQLite database on your machine. On the installed Windows app that is %APPDATA%\AI-Cost-Management\data\. Uninstalling the app removes the program files but keeps your data.

Does the budget stop me from overspending?

No. Budgets only display status inside the app — progress, warnings, and forecasts on the Budget page. Nothing is blocked, no push notifications or alerts are sent, and no spending is interrupted.

Is AI Activity a real-time monitor?

No. It takes an on-demand snapshot of local processes and network connections when you open the page (results are cached briefly, and you can refresh manually). The results are activity evidence, not proof that money was spent. History is kept only in memory and is cleared when the app restarts. Detection can produce false positives, and it works on Windows only.

Does the app send anything over the network?

We found no code that uploads your usage or cost data, and no analytics or crash-reporting code in the application. Two known exceptions are documented above: reverse DNS lookups while the AI Activity scan runs, and the optional provider connectivity test you trigger yourself.

Which systems are supported?

Windows x64. The minimum supported Windows version and the installer's code-signing status are not confirmed yet — treat both as to-be-confirmed until published here.

Which import formats are supported?

The official DeepSeek usage export ZIP (usage_data_*.zip), parsed locally in two steps with a confirmation before anything is written to your database.

Is the project open source? What license does it use?

No license has been published in the repository yet. Check the repository for updates before redistributing, and do not assume open-source terms.
